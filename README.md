# 高中知识图谱（人教版）

网页版交互式高中知识图谱，覆盖人教版全套教材三个学科：

- **物理**：6 册教材 · 27 章 · 125 节 · 143 知识点
- **生物学**：5 册教材 · 25 章 · 82 节 · 129 知识点
- **地理**：5 册教材 · 24 章 · 67 节 · 93 知识点（附 ★ 考点重要度与高频考点标注）

数据目录提取自国家中小学智慧教育平台的人教版电子教材。

## 在线使用

用任意静态服务器根目录部署即可，例如：

```bash
python3 -m http.server 8734
# 打开 http://127.0.0.1:8734/index.html
```

无任何外部依赖（自研 Canvas 力导向布局，无框架、无 CDN），离线可用。

## 功能

- 总览页三科导航；每科独立图谱页（章节 4 级结构 + 跨章知识关联）
- 搜索定位（回车逐个跳转）、教材分册显隐、适配视图、重新布局、暂停运动
- 点击节点查看详情：知识点释义、考点重要度（★1–★5）、高频考点、易错点、
  经典例题、公式推导、图像解析（内置 SVG 插图，如地质年代表、大气受热过程等）
- 地理页知识点附带五类逻辑关联：基础 / 深化 / 因果 / 应用 / 联系

## 文件结构

```
├── index.html      总览（三科入口）
├── physics.html    物理图谱页
├── biology.html    生物学图谱页
├── geo.html        地理图谱页
├── style.css       全部样式（深色主题）
├── app.js          Canvas 力导向图引擎 + 交互
├── data.js         教材目录树（册→章→节）+ 跨章关联
└── knowledge.js    知识点标注 + 知识点间关联
```

## 扩展数据

- 新增教材章节：编辑 `data.js` 的 `BOOKS`（节点编号 `<书id>c<章号>`，节按索引 `s<序号>`）
- 新增知识点：编辑 `knowledge.js` 的 `KNOWLEDGE`（字段 id/sec/type/label/text，可选
  imp 考点重要度、exam 考点、wrong 易错点、example 例题、derive 推导、img 插图键名）
- 新增关联：`KP_LINKS`（a/b 为知识点 id，kind 为关系类型，note 为说明）
- 新增插图：`app.js` 的 `KP_IMG` 图库中添加 SVG，知识点 `img` 字段引用键名
